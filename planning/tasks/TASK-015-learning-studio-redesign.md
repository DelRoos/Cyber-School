# TASK-015 — Studio scientifique et apprentissage guidé

## Objectif

Repenser l'accueil et les deux expériences de cours pour des débutants, avec une identité sombre scientifique choisie par l'utilisateur. Renforcer les compétences et les adaptateurs des trois agents sans altérer les travaux V4 présents dans l'arbre de travail.

## Critères d'acceptation

- [x] Accueil avec catalogue réel, recherche et filtres utilisables, hiérarchie visuelle originale et navigation cohérente.
- [x] Cours mémoire guidé par chapitre avec exemple expliqué, manipulation, exercices, transitions et mode de consultation complète.
- [x] Cours TCP avec introduction accessible, scénario expliqué et simulateur conservant les cas de perte et les contrôles clavier.
- [x] Typographie locale, contrastes lisibles, focus clavier, absence de débordement à 375 px, mouvement réduit respecté.
- [x] Skills pédagogiques et adaptateurs Codex/Claude/Gemini renforcés ; ressource externe épinglée, licenciée et miroirs synchronisés.
- [ ] Contrôles complets et tests navigateur réussis après la dernière modification ; captures ordinateur/mobile inspectées.

- [x] Les clôtures déjà commitées conservent leurs preuves historiques intactes ; les nouvelles validations et publications refusent toute preuve périmée.

- [ ] Les dix skills sont détectés par Gemini dans le dossier approuvé et les agents Claude peuvent activer les skills pertinents par domaine.
